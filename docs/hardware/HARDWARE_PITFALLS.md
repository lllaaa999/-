# 硬件避坑红宝书 (Hardware Pitfalls)

在制作小型智能拟四足机器人的过程中，有几个极易让初学者陷入困境的“隐形硬件陷阱”。本文档将这些踩坑经验整理归纳，助你一次点亮、平稳运行。

---

## 陷阱 1：舵机瞬态大电流引发 MCU 掉电重启 (Brownout)
* **故障现象**：小狗开机一切正常，但一旦迈出第一步或四个舵机同时动作，ESP32 和 STM32 瞬间断电重启，表现为“一动就死机”。
* **底层原因**：
  MG90S 舵机在静止启动或受阻堵转的瞬间，会产生高达 **0.8A~1.2A 的瞬态电流脉冲**。4 个舵机同时动作，峰值瞬间可达 **3A 以上**！普通的 5V 1A~2A 充电宝升压板瞬间供不上电，输出电压跌落至 3.8V 以下，触发了单片机内部的低压复位机制（Brownout Reset）。
* **终极对策**：
  1. 升级为 **5V 3.5A 同步升压板**（基于 FP6276 方案），绝不使用廉价普通充电宝电路板；
  2. 在舵机 5V 供电脚附近，**并联 1 颗 1000µF/16V 或 2200µF/10V 的低 ESR 电解电容**。电容就像一个本地“蓄水池”，在舵机急抽电流的几十毫秒内瞬间放电，把电压牢牢稳住！

## 陷阱 2：摄像头排线过短与高频信号干扰
* **故障现象**：
  * 原装排线只有 2cm，小狗肚子里的板子连不到头部的摄像头；
  * 换了太长的线（例如 20cm 散线），摄像头画面出现大片绿色雪花条纹、花屏甚至初始化报错 `Camera probe failed`。
* **底层原因**：
  ESP32-S3-CAM 上的 OV2640 走的是 DVP 并行总线，XCLK 和像素时钟高达 20MHz。并行高频信号在长导线上传播会产生严重的阻抗失配和电机电磁辐射串扰。
* **终极对策**：
  1. 选购专用的 **75mm 24Pin 0.5mm 间距** 的加长排线摄像头（75mm 是机械狗头颈走线的“黄金长度”，兼顾了活动余量与高频信号完整性）；
  2. 走线时让摄像头排线尽量**远离舵机动力线**，不要紧贴着舵机马达外壳。

## 陷阱 3：音频啸叫（声反馈）与功放“滋滋”电磁杂音
* **故障现象**：
  * 小狗自言自语时，突然发出尖锐刺耳的啸叫声；
  * 舵机一转动，喇叭里就同步传出急促的“滋滋”马达转动杂音。
* **底层原因**：
  1. 麦克风（INMP441）和喇叭装得太近，小狗自己说出的话直接被麦克风二次吸入，形成闭环正反馈放大（声学啸叫）；
  2. 舵机的电刷火花和地线电流波动，通过共用地线直接窜入了敏感的 MAX98357A 功放芯片中。
* **终极对策**：
  1. **声学物理隔离**：喇叭必须选**带密封音腔的 2030 腔体喇叭**，防止声音在小狗头腔内乱窜；在 INMP441 麦克风背面贴一层 **EVA 减震吸音海绵**，阻断机械共振传声；
  2. **星形单点接地**：舵机动力地与音频信号地在电源板输出端分开，绝不串联走线。

## 陷阱 4：劣质塑料齿舵机扫齿与打滑
* **故障现象**：
  小狗从桌上摔下一次，或者脚卡在电线上，舵机内部发出“咔咔咔”空转声，再也无法承重站立。
* **底层原因**：
  廉价的 SG90 塑料齿舵机极易在受到外部冲击时崩断齿轮齿尖（俗称“扫齿”）。
* **终极对策**：
  1. 坚持选用 **MG90S 金属齿舵机**，金属齿轮可以承受数倍于塑料齿的机械冲击；
  2. 4 只脚底必须粘贴 **半球形橡胶防滑脚垫**，增加摩擦力，避免小狗像在溜冰场一样原地踏步打滑。
