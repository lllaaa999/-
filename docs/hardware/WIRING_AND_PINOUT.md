# 引脚定义与电路拓扑规范 (Wiring & Pinout)

本文档规范了《复苏计划》硬件系统的各模块引脚互连关系、通信协议引脚与供电布线拓扑。

---

## ⚠️ ESP32-S3-CAM 引脚避坑原则
ESP32-S3-CAM 上的 DVP 摄像头接口占用了大量的 GPIO（包括 `GPIO10~18` 等像素总线与时钟线）。  
**严禁将摄像头占用的引脚复用给其他外设！** 下表给出的引脚分配方案已严格避开摄像头总线，确保各模块互不冲突。

---

## 📌 ESP32-S3-CAM 引脚分配表

### 1. I2S 数字音频输入 (INMP441 麦克风)
| INMP441 引脚 | ESP32-S3 GPIO | 说明 |
|---|---|---|
| **VCC** | **3.3V** | 麦克风供电 |
| **GND** | **GND** | 信号地 |
| **SD (Serial Data)** | **GPIO 4** | 音频数据输入 (I2S0_DATA_IN) |
| **WS (Word Select)** | **GPIO 5** | 左右声道时钟 / 采样帧同步 (LRCK) |
| **SCK (Serial Clock)** | **GPIO 6** | 位时钟 (BCLK) |
| **L/R** | **GND** | 接地，选择左声道输出 |

### 2. I2S 数字音频输出 (MAX98357A 功放)
| MAX98357A 引脚 | ESP32-S3 GPIO | 说明 |
|---|---|---|
| **Vin** | **5V (或 3.3V)** | 建议接干净的 5V，输出功率充足 |
| **GND** | **GND** | 信号地 |
| **DIN (Data In)** | **GPIO 7** | 音频数据输出 (I2S1_DATA_OUT) |
| **LRC (Word Select)**| **GPIO 1** | 声道时钟 (LRCK) |
| **BCLK (Bit Clock)** | **GPIO 2** | 位时钟 (BCLK) |
| **SD_MODE** | 悬空 / 上拉 | 默认左右声道混音 |
| **GAIN** | 悬空 (默认 9dB) | 增益引脚 |

### 3. I2C 显示屏 (0.96" SSD1306 OLED)
| OLED 引脚 | ESP32-S3 GPIO | 说明 |
|---|---|---|
| **VCC** | **3.3V** | 屏幕供电 |
| **GND** | **GND** | 信号地 |
| **SCL** | **GPIO 8** | I2C 硬件时钟线 |
| **SDA** | **GPIO 9** | I2C 硬件数据线 |

### 4. UART 身脑协同串口 (对接 STM32F103)
| ESP32-S3 引脚 | 对接端 (STM32F103) | 说明 |
|---|---|---|
| **GPIO 43 (U0TXD)** | **PA10 (USART1_RX)** | S3 发送动作指令至 STM32 |
| **GPIO 44 (U0RXD)** | **PA9 (USART1_TX)** | S3 接收 STM32 运动状态回传 |
| **GND** | **GND** | **必须共地！** |

## 📌 STM32F103C8T6 下位机引脚分配表

STM32 专职负责四腿舵机控制与步态产生，采用定时器硬件 PWM 驱动：

| 功能模块 | STM32F103 引脚 | 定时器通道 | 说明 |
|---|---|---|---|
| **前左腿 (FL) 舵机** | **PA0** | TIM2_CH1 | 输出 50Hz PWM 脉冲 (0.5ms~2.5ms) |
| **前右腿 (FR) 舵机** | **PA1** | TIM2_CH2 | 输出 50Hz PWM 脉冲 (0.5ms~2.5ms) |
| **后左腿 (BL) 舵机** | **PA2** | TIM2_CH3 | 输出 50Hz PWM 脉冲 (0.5ms~2.5ms) |
| **后右腿 (BR) 舵机** | **PA3** | TIM2_CH4 | 输出 50Hz PWM 脉冲 (0.5ms~2.5ms) |
| **身脑通信串口** | **PA9 (TX)** / **PA10 (RX)** | USART1 | 与 ESP32-S3 全双工通信 (115200) |
| **SWD 烧录口** | **SWDIO / SWCLK** | - | 接 ST-Link V2 下载器 |

## ⚡ 供电系统抗干扰连线拓扑

```
                 [ 3.7V 2800mAh 104050 软包锂电 (带板) ]
                                   │
                      [ 5V 3A 同步升压板 (FP6277 / FP6296) ]
                                   │
              ┌────────────────────┴────────────────────┐
              │ 5V (动力电源)                            │ 5V (逻辑电源)
              ▼                                         ▼
      ┌───────────────┐                         ┌───────────────┐
      │  4× SG90 舵机 │                         │  ESP32-S3-CAM │
      │  VCC / GND    │                         │  STM32F103    │
      └───────┬───────┘                         └───────┬───────┘
              │                                         │
              ├────────── 并联 1000µF/16V 电容 ────────┤
              │ (紧靠舵机排针座)                        │
              │                                         │
              ▼                                         ▼
      【 动力地 (PGND) 】                       【 信号地 (AGND/DGND) 】
              │                                         │
              └─────────────── 单点共地 ────────────────┘
                            (在电源板输出端汇合)
```

### 接线黄金法则：
1. **电容必须并联在动力端**：1000µF 电容必须焊在舵机 5V 和 GND 排针的正负极端子处，引线越短越好，才能最快释放电荷补充瞬态电流。
2. **单点接地防滋滋杂音**：舵机动力地电流很大，不要把舵机地线串联过 MCU 或麦克风再回电源！必须像上图一样，动力地与信号地分别拉线回到升压板的 GND 输出脚（星形单点接地）。
