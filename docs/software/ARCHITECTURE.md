# 身脑协同软件架构与串口通信协议 (Software Architecture)

在《复苏计划》中，**ESP32-S3 作为“大脑”，STM32 作为“身体”**。两者通过标准 UART 串口进行全双工解耦通信。

## 📡 身脑串口通信协议规范

为了兼顾调试的直观性与单片机解析的低开销，通信协议采用 **带校验的 ASCII 文本定界帧**。

* **物理层参数**：波特率 `115200`，数据位 `8`，停止位 `1`，无奇偶校验 (`8-N-1`)。
* **帧格式约定**：`$CMD,<类型>,<参数1>,<参数2>#\n`
  * 帧头：`$`
  * 帧尾：`#\n`
  * 分隔符：`,`

---

### 1. 大脑发往身体（动作控制命令）

| 指令字符串 | 含义 | 参数说明 | 示例 |
|---|---|---|---|
| `$ACT,STAND#` | 站立/复位 | 无 | `$ACT,STAND#` |
| `$ACT,FORWARD,<步数>#` | 前进 | 步数 (1~20) | `$ACT,FORWARD,5#` (向前走5步) |
| `$ACT,BACK,<步数>#` | 后退 | 步数 (1~20) | `$ACT,BACK,3#` |
| `$ACT,TURN_L,<步数>#`| 左转 | 步数 | `$ACT,TURN_L,4#` |
| `$ACT,TURN_R,<步数>#`| 右转 | 步数 | `$ACT,TURN_R,4#` |
| `$ACT,HELLO#` | 挥手打招呼 | 无 (抬起右前腿摇晃) | `$ACT,HELLO#` |
| `$ACT,SIT#` | 坐下休息 | 无 | `$ACT,SIT#` |
| `$TRACK,<偏移X>,<偏移Y>#`| 头部跟随追踪 | 视线中心偏差 (-100~100) | `$TRACK,25,-10#` |

---

### 2. 身体回传大脑（状态与事件上报）

| 上报字符串 | 含义 | 触发场景 |
|---|---|---|
| `$STA,OK#` | 指令已接收并开始执行 | STM32 成功接收合法指令后立即应答 |
| `$STA,DONE#` | 动作执行完毕 | 步数走完或打招呼动作完成后发送 |
| `$EVT,FALL#` | 倾倒报警（若加装 MPU6050） | 摔倒触发，通知大模型发出呼救语音并切换为哭泣表情 |
| `$BAT,<电压百分比>#` | 电量汇报 | 定时上报（如 `$BAT,85#` 代表剩余 85% 电量） |

## 💡 代码落地提示

### STM32 状态机解耦伪代码：
```c
// 伪代码示例：在定时器中断中平滑更新舵机角度
void TIM2_IRQHandler(void) {
    if (g_robot_state == ROBOT_WALK_FORWARD) {
        // 三角函数步态轨迹解算
        float angle_FL = calc_gait_phase(time_tick, 0);
        float angle_FR = calc_gait_phase(time_tick, PI);
        float angle_BL = calc_gait_phase(time_tick, PI);
        float angle_BR = calc_gait_phase(time_tick, 0);
        
        Set_Servo_Angle(SERVO_FL, angle_FL);
        Set_Servo_Angle(SERVO_FR, angle_FR);
        Set_Servo_Angle(SERVO_BL, angle_BL);
        Set_Servo_Angle(SERVO_BR, angle_BR);
    }
}
```
通过本套通信协议，S3 上的大模型可以随时通过一行简单的 `uart_write_bytes("$ACT,HELLO#")` 让机械狗生动起来！
