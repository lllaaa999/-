# 项目分阶段实施与验收规划 (Implementation Plan)

本文档将《复苏计划》划分为三个可清晰交付的阶段，并为每个阶段制定具体的软硬件测试与验收标准。

---

## 阶段 1：大脑启动 —— 语音对话与动态表情

### 目标：
让机器人具备“思考、倾听、说话、表达表情”的完整上位机功能。

### 任务清单：
* [ ] **硬件焊接与搭线**：
  * 将 INMP441 麦克风接入 ESP32-S3-CAM 的 GPIO 4/5/6；
  * 将 MAX98357A 功放接入 GPIO 1/2/7，并接好 2030 音腔小喇叭；
  * 将 0.96 寸 OLED 接在 GPIO 8/9 (I2C)；
  * 麦克风背面贴附 EVA 吸音泡棉。
* [ ] **固件与网络调试**：
  * 烧录小智 AI 开源固件（xiaozhi-esp32）；
  * 配置 Wi-Fi 配网，对接大语言模型（LLM）API；
  * 调通唤醒词唤醒（如“小智小智”或自定义唤醒词）。
* [ ] **表情驱动**：
  * 调通 SSD1306 OLED 显示驱动，制作眨眼、思考、开心、惊讶 4 套核心表情动画。
* [ ] **验收标准**：
  * 对着它说话，1.5 秒内能获得大模型流畅的语音回答；
  * 说话时 OLED 同步呈现灵动的表情动画；
  * 喇叭声音清脆洪亮，无尖锐啸叫或严重破音。

---

## 阶段 2：身体赋能 —— 四足步态与稳固动力

### 目标：
完成机械骨架组装，让机器人能够稳健走路、转向，并彻底验证电源防掉电能力。

### 任务清单：
* [ ] **骨架与舵机装配**：
  * 3D 打印件打磨与腿部骨架安装；
  * 四只脚底贴上 3M 半球形橡胶脚垫；
  * 舵机上电并校准至 90° 绝对零点后再锁螺丝固定腿部。
* [ ] **STM32 步态编程**：
  * 在 Keil MDK 或 STM32CubeIDE 下配置 TIM2 产生 4 路 50Hz PWM；
  * 编写对角小跑（Trot）或爬行步态生成算法；
  * 实现基本动作集：站立、前进、后退、左转、右转、打招呼。
* [ ] **供电系统抗冲击压力测试**：
  * 接入 5V 3.5A 升压板，并在舵机动力端并联 1000µF 储能电容；
  * 编写满负荷测试代码：命令 4 个舵机同时以最高速度往返剧烈摆动；
* [ ] **验收标准**：
  * 机械狗能在光滑桌面上平稳向前移动，不打滑、不倾倒；
  * 在 4 舵机剧烈抽流测试下，单片机 100% 不发生复位重启。

## 阶段 3：身脑合一 —— 视觉追踪与多模态联动

### 目标：
装上加长版眼睛，实现人脸抓取、视觉跟随与“说一句动一下”的身脑大联动。

### 任务清单：
* [ ] **摄像头穿线与视野校正**：
  * 将 75mm 加长版 OV2640 摄像头插上 S3 接口，排线穿过脖子固定在头部；
  * 开启 120° 广角镜头，确保视野开阔无遮挡。
* [ ] **人脸检测与目标追踪**：
  * 开启 ESP-WHO / 轻量人脸检测算法；
  * 提取人脸中心相对于镜头画面的像素偏差 `(offset_x, offset_y)`。
* [ ] **身脑串口协议打通**：
  * 连接 ESP32-S3 (GPIO 43/44) 与 STM32 (PA9/PA10) 的串口，并接好共地线；
  * 大模型完成意图识别后，通过串口向 STM32 下发 `$ACT,FORWARD#` 等命令；
  * 将人脸坐标偏差以 `$TRACK,x,y#` 发送给下位机，驱动小狗微调站姿，让视线始终跟随主人。
* [ ] **最终整机验收标准**：
  * 主人走到桌前，小狗主动发现人脸并对视；
  * 主人对它说：“往前走两步”，小狗语音回应“好的主人！”，同时迈腿向前平稳爬行两步后停下立正。
